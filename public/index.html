World map · how it works

Five stages from signal to safety

Real cryptographic bounties measure attacker capability. That measurement becomes one number. Everything else reacts to that number.

1-1Canary

Bounty keys on fourteen curves, from toy 16-bit up to secp256k1. Anyone can submit a solution; the server checks k·G = Q itself.

1-2Oracle

Each broken armed rung (192-bit and up) lifts the threat level by one step, from 0 to 4. Training rungs never move it.

1-3Guard

Contracts that inherit AxionGuard freeze chosen functions once the level crosses the threshold you picked.

1-4Ark

Commit the hash of an ML-DSA-44 public key now. Later, that key proves you are the owner, even if ECDSA is broken.

1-5Alerts

Subscribe once and get pinged the moment the level moves. Dashboards and bots can poll the public JSON API.

THE AXION MOMENT

The first time an armed rung falls. It is stamped with a timestamp and every module switches to defense mode.

FAQ

Can AXION OS stop a quantum computer?

No software can. AXION OS detects the capability the moment someone proves it, and triggers the protections you prepared ahead of time: frozen functions, a recovery key and alerts.

What if an attacker never claims a bounty?

Then the canary stays quiet. That is exactly why Ark and Guard should be set up early instead of after an alarm.

Do my keys ever leave the browser?

No. ML-DSA keys are generated and used in your tab. The server only ever sees a 32-byte keccak256 commitment, and the recovery kit is downloaded straight to your device.

Why can some rungs be cracked in a browser?

Training rungs (16–40 bit) are deliberately tiny so you can see the full flow end to end. They earn leaderboard points but never move the threat level.

Who knows the private keys of the armed rungs?

Nobody. Their target points are derived by hashing a public phrase onto the curve, so no one, including us, ever had the matching scalar.

Is it live on mainnet?

The console and API are live. Contracts are reference implementations awaiting testnet and audit; the app already builds correct calldata for them.
